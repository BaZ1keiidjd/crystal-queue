Подключение

Очередь хранится в приватном GitHub Gist: телефон пишет туда задачи, раннер на ПК их забирает и выполняет через opencode.

Создать: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → отметить только gist. Токен хранится в этом браузере.

Оставь пустым — создам новый приватный gist автоматически. Если уже есть (например, созданный раннером), вставь его ID.

Как часто перечитывать gist, чтобы видеть статусы выполнения.

node runner/runner.mjs --setup

Запусти это в папке task-queue на компьютере — раннер сам создаст gist (если нужно), сохранит конфиг и начнёт выполнять задачи.
